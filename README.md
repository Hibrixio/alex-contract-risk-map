# UCC–Intellibus MOU Contract Risk Map

An interactive executive review tool for the UCC and Intellibus draft Memorandum of Understanding.

## Features

- Interactive 3D clause and risk map
- Movable, color-coded risk cards
- Priority-ordered executive recommendation log
- Search and category filters
- Source-document highlights and full MOU viewer
- CSV export and print/PDF support

## Live site

https://alex-contract-risk-map.vercel.app/

## Run locally

This is a static site. Open `index.html` directly, or serve the folder with any static web server.
